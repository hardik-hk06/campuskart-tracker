# CampusKart Tracker 🛺

A real-time tracking platform that helps college students track CollegeKart service vehicles, view their live locations, and estimate arrival times.

## 🚀 Project Goal

To make campus transportation and CollegeKart services more transparent and convenient for students through real-time location tracking and ETA estimation.

## ✨ Planned Features

- Live vehicle tracking on a map
- Estimated time of arrival (ETA)
- Vehicle availability
- Order/ride status tracking
- Student dashboard
- Driver location sharing
- Backend API for location and tracking data

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **Database:** MongoDB
- **Maps:** OpenStreetMap
- **Realtime:** Socket.IO
- **Version Control:** Git & GitHub
